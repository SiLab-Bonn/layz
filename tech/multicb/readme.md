# multicb

Multi-CB's published standard buildups, one stack file each (`--stack multicb/4L-01`):

| Process | | Source |
| --- | --- | --- |
| `4L-01` | 4-layer FR4, 1.6 mm | defined buildup 4L-01 (mask assumed: 10 µm, εr 3.3) |
| `4L-02` | 4-layer FR4, 1.0 mm | defined buildup 4L-02 (mask assumed) |
| `flex_2F-l` | 2-layer flex, adhesiveless, 161 µm | standard 2F-l |
| `flex_2F-a` | 2-layer flex, adhesive-bonded, 187 µm | standard 2F-a |

For a board ordered with a custom buildup, copy the closest one and enter the ordered thicknesses
and materials.
